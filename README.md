# Thực hành 1 - Blog Listing Page

## Thông tin sinh viên
- Họ tên: Tạ Thanh Tâm
- MSV: N25DCAT103

## Mô tả bài làm
Xây dựng Blog Listing Page bằng NextJS và Tailwind CSS.

Bài làm bao gồm:
- Hiển thị danh sách bài viết từ JSONPlaceholder API.
- Giao diện Blog Listing dạng Grid Responsive.
- Trang chi tiết bài viết theo dynamic route `/blog/[id]`.
- Nút Read More để xem chi tiết bài viết.
- Nút Back to Blog để quay lại danh sách bài viết.
